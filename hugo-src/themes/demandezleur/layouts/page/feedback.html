Partager un retour

Votre expérience nous intéresse. Ce formulaire permet d'envoyer un message directement à la personne qui maintient le projet.

Comment ça marche

  • C'est anonyme — aucun email, aucun nom, aucun cookie de tracking n'est collecté. Seul votre message est transmis.
  • Ce n'est pas public — votre message n'est pas affiché sur le site. Il est simplement envoyé au mainteneur du projet via un canal privé.
  • Pas de réponse automatique — puisque vous n'avez pas laissé de coordonnées, il n'y a pas de canal pour vous répondre. Si votre message appelle une réponse, mentionnez-le et indiquez un moyen de vous joindre dans le texte.
